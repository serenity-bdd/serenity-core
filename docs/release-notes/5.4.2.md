# Serenity BDD 5.4.2 Release Notes

**Security Updates and Smaller Releases**

This release updates a number of dependencies to address known security advisories, and continues to reduce the size of the artifacts published to Maven Central. There are no API changes.

## Security Updates

| Dependency | Previous | Now | Module |
|------------|----------|-----|--------|
| FreeMarker | 2.3.34 | 2.3.35 | `serenity-model`, `serenity-core` |
| Thymeleaf | 3.1.4.RELEASE | 3.1.5.RELEASE | `serenity-single-page-report` |
| Jackson | 2.21.6 | 2.21.7 | all modules |
| Apache HttpClient 5 | 5.4.4 | 5.6.3 | all modules |
| Bouncy Castle (`bcprov-jdk18on`) | 1.78 | 1.85 | `serenity-browsermob-plugin` |
| plexus-utils | 3.2.1 | 3.6.1 | `serenity-maven-plugin` |

Together these address four critical and several high and medium severity advisories, including path traversal in FreeMarker template loading, a sandbox bypass in Thymeleaf, and denial-of-service issues in Jackson. We recommend upgrading from 5.4.1 or earlier.

## Smaller Artifacts

Maven Central now applies monthly publishing limits, so Serenity's published artifacts have been trimmed. A full release is now about 65 MB, down from about 88 MB for 5.4.0, and this release reduces it further.

- **Smaller `serenity-cli` jar.** The shaded command-line jar, used by Serenity/JS, went from about 66 MB to about 37 MB. It now depends on Flexmark core instead of the full Flexmark bundle, drops an unused ICU dependency, and no longer bundles ByteBuddy and Ehcache, which only the test-execution modules use. This first shipped in 5.4.1.
- **Leaner Javadoc jars.** The generated Javadoc no longer includes web fonts (shipped in 5.4.1) or the `class-use` pages, which makes the Javadoc jars about a third smaller. The "Use" links on class pages are no longer generated; the API, search and package documentation are unchanged.
- **Unused icon assets removed.** The HTML reports use only the Bootstrap Icons stylesheet and its fonts, so the icon sprite, about 1,950 individual SVG files, and the SCSS and JSON sources have been removed from `serenity-report-resources`. That jar went from 4.0 MB to 2.7 MB.

### Upgrade note: custom report templates

If you have custom report templates that reference individual Bootstrap Icons SVG files or the `bootstrap-icons.svg` sprite directly, those files are no longer shipped. The standard Serenity reports use the icon font and are not affected.

## Build and Release

- The release workflow derives the release version from the current `SNAPSHOT` version, and the separate `deploy-cli` release profile has been removed. The CLI is now published with the rest of the modules.
- The release is built on JDK 25 (needed for the Javadoc `--no-fonts` option). Code is still compiled with `--release 17`.
- An empty `net.thucydides.core.resources` package was removed from `serenity-core`.
- `ManualScenarioChecker` in `serenity-cucumber` now uses `String.isBlank()` instead of jsoup's internal `StringUtil`.
- Modules that are only built under non-default profiles (`serenity-bitbar`, `serenity-jira-plugin`, `serenity-jira-requirements-provider`, `serenity-lambdatest`, `serenity-navigator-report`, `serenity-playwright`, `serenity-screenplay-playwright`, `serenity-selenoid` and `serenity-smoketests`) now point at the current parent version.
- Test and sample dependencies were updated for security advisories: Jetty (test scope) in `serenity-rest-assured`, and AssertJ and Jackson in `serenity-tutorials`. These do not affect published artifacts.

## Upgrade

Using the BOM (recommended):

```xml
<dependencyManagement>
    <dependencies>
        <dependency>
            <groupId>net.serenity-bdd</groupId>
            <artifactId>serenity-bom</artifactId>
            <version>5.4.2</version>
            <type>pom</type>
            <scope>import</scope>
        </dependency>
    </dependencies>
</dependencyManagement>
```

Or update the version directly:

```xml
<dependency>
    <groupId>net.serenity-bdd</groupId>
    <artifactId>serenity-core</artifactId>
    <version>5.4.2</version>
</dependency>
```
